# Join the Revolution: Open Source in Academia

Slides for the Nava Open Source Summit, built with Quarto (`lexis-revealjs` theme, after JP Helveston's posit::conf 2026 deck).

- `index.qmd` is the deck. Edit it, then run `quarto render index.qmd`.
- `index.html` and `index_files/` are the rendered output. They are committed and served by GitHub Pages.
- `_extensions/` holds the lexis, iconify and fontawesome extensions. Don't hand-edit.
- `custom.css` is the only local stylesheet.

## Publish

In the GitHub repo: Settings → Pages → Deploy from a branch → `main` / root.
